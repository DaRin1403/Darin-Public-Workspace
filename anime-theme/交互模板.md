# 交互样式标准模板 v1

> 用途：给任何"新元素 / 漏网之鱼"上漆时的**标准做法**。照模板填类名即可，不用重新设计。
> 配套文档：`设计规范.md`（当前生效值）· `交互架构方案.md`（分层与应急）。

---

## 一、标准解释（当前方案的底层逻辑）

1. **三态梯度铁律**：任何粉色交互单元，颜色深浅必须满足
   `常驻(L0) < 悬停 < 按下` —— 改任何一档，必须检查另外两档梯度是否还成立。
2. **菜单层级铁律**：
   - 菜单面板 = 浅粉玻璃（粉 78%/55% + blur 10），条目不抢面板的色；
   - 菜单条目 = **静止透明黑字 → 悬停艳粉白字 → 按下深粉**（2026-08-19 定稿方案）；
   - 菜单条目的 `:focus-visible` 不上粉（点击残留会变"永久悬停"）。
3. **语义色军规**：蓝（业务/发送/运行）、红、绿、黄不参与任何粉化。
4. **特异性铁律**：豁免链必须与常驻规则**同长**（少一个 `:not` 就被压住）；`:active` 写在 `:hover` 之后；portal 到 body 的浮层用全局作用域选择器。
5. **变量账本**：同层同配方，全部走 `--kaguya-*` 变量（见第四节），改色只改变量。

## 二、模板（填空即可用）

> 使用方式：把 `.Xxx` 换成实际类名，把注释换成元素名，整块粘进 client.js 对应"══ 分区 ══"。

### 模板 A · L0 粉玻璃按钮（有身份的常驻按钮，如"新会话/设置"同款）

```css
/* L0 按钮：<元素名> */
body:not([data-ds-dark-theme]) .Xxx {
  background: var(--kaguya-base) !important;   /* 设置面板款换 --kaguya-base-soft；收起模式换 --kaguya-base-rail */
  color: #ffffff !important;                    /* 设置面板款换 #222222 */
  border: 1px solid rgba(255,255,255,0.55);
  border-radius: 12px;
  box-shadow: inset 0 1px 0 rgba(255,255,255,0.55), inset 0 -1px 0 rgba(140,60,100,0.16), 0 3px 10px rgba(200,110,155,0.3);
}
body:not([data-ds-dark-theme]) .Xxx:hover { background: var(--kaguya-hover) !important; }
body:not([data-ds-dark-theme]) .Xxx:active { background: var(--kaguya-press) !important; box-shadow: inset 0 2px 4px rgba(120,40,85,0.25); }
```

### 模板 B · L0 轻按钮（静止无底色，如标签/工作区行）

```css
/* L0 轻按钮：<元素名> */
body:not([data-ds-dark-theme]) .Xxx { border-radius: 10px; }          /* 静止透明，只定形 */
body:not([data-ds-dark-theme]) .Xxx:hover {
  background: linear-gradient(rgba(240,155,196,0.4), rgba(228,145,184,0.32)) !important;
  box-shadow: inset 0 1px 0 rgba(255,255,255,0.5);
}
body:not([data-ds-dark-theme]) .Xxx:active { filter: brightness(0.9); box-shadow: inset 0 2px 3px rgba(0,0,0,0.15); }
```

### 模板 C · L1/L2/L3 菜单面板（点按钮弹出的浮层）

```css
  -webkit-backdrop-filter: blur(10px) saturate(155%);
  backdrop-filter: blur(10px) saturate(155%);
  border-color: rgba(255,255,255,0.6);

```

### 模板 D · 菜单条目（★当前定稿方案：静止透明黑字 → 悬停艳粉白字 → 按下深粉）

```css
/* 菜单条目：<元素名>（静止透明黑字 = 官方原样，无需写静止态） */
body:not([data-ds-dark-theme]) .Xxx:hover {
  background: var(--kaguya-hover) !important;
  color: #ffffff !important;
}
/* 子文字随悬停转白：主文字纯白、次要信息 85% 白 */
body:not([data-ds-dark-theme]) .Xxx:hover .Xxx-name,
body:not([data-ds-dark-theme]) .Xxx:hover .Xxx-icon { color: #ffffff !important; }
body:not([data-ds-dark-theme]) .Xxx:hover .Xxx-desc { color: rgba(255,255,255,0.85) !important; }
/* 按下（必须比悬停更深） */
body:not([data-ds-dark-theme]) .Xxx:active { background: var(--kaguya-press) !important; }
```

## 三、给新元素上漆的标准流程（五步）

1. **定位**：看它在哪个界面 → 搜 `══ 分区：… ══` 找到所属分区；
2. **定类名**：从官方包的 class map 拿实际类名（哈希类名），核对服务器实际发出的包；
3. **定层级**：按钮本体=L0；点开的浮层=L1；浮层里再点=L2…（参照交互架构方案矩阵）；
4. **套模板**：按层级选 A~F 模板，填入类名；**豁免链与常驻规则同长**；
5. **验证**：F5 → 三态梯度检查（常驻<悬停<按下）→ 语义色未误伤 → 截图给 AI 复核。

## 四、变量账本（当前值，改色只改这里）

| 变量 | 用途 | 当前值 |
|---|---|---|
| `--kaguya-base` | A 主款常驻 | 238,120,180 72% / 224,100,165 55% |
| `--kaguya-base-soft` | 设置面板款常驻 | 246,175,205 75% / 238,160,195 62% |
| `--kaguya-base-rail` | 收起模式常驻 | 238,120,180 65% / 224,100,165 50% |
| `--kaguya-hover` | 全部粉色悬停/选中 | 236,90,163 95% / 224,80,152 85% |
| `--kaguya-hover-soft` | 悬停浅档 | 236,90,163 70% / 224,80,152 55% |
| `--kaguya-press` | 全部粉色按压（= 黑 12% 叠艳粉） | 恒比悬停深一档 |

---

## 五、模板使用纪律

- 能套模板就不写新数值；**新数值 = 新特例**，要写进规范的特例清单；
- 每新增一个单元，在"交互架构方案"的矩阵表里登记一行（界面 × 层级 × 类名）；
- 改动后顺手检查：三态梯度、语义色、深色模式未动、菜单 focus-visible 未上粉。
