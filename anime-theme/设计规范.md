## 一、语义色军规（永远不碰）

蓝（运行/业务）、红（错误）、绿（成功）、黄（警告）：携带状态含义，永不改色。
例外（经用户确认）：插件列表"已启用"徽章保留绿色但做玻璃化。

## 二、按钮四大类（⭐悬停特注）

### A 类 · 粉玻璃重按钮（常驻粉色，有身份）

成员：新会话、侧栏设置、输入框 5 个普通按钮（+ / full access / plan / 模型 / 上下文计量）、
session log、弹窗主按钮（关闭/确定）、设置面板按钮、搜索/清除键、收缩模式按钮。

| 状态 | 主款 | 设置面板款（更淡+黑字） | 弹窗主按钮款（深一档） |
|---|---|---|---|
| 常驻 | 粉 62%/44% + 白字 | 粉 65%/50% + 黑字 #222 | 粉 72%/55% + 白字 |
| ⭐悬停 | **加深 82%/66%** | **加深 86%/70%** | **加深 90%/74%** |
| 按下 | 实色 85% + 内凹 | 实色 92% + 内凹 | 实色 95% + 内凹 |

⭐悬停原则：**同色系往下踩一档**（62→82→85 一根粉轴上滑），不换色、不加白。
（2026-08-18 用户要求"所有悬停加深一档"：主款 75/58→82/66、设置款 78/62→86/70、主按钮款 85/68→90/74、弹窗关闭钮 62/44→72/55；撤回=恢复 `client.js.bak-hover-bump`）

### B 类 · 轻按钮（静止无底色，悬停才显形）

成员：工作区行、顶部"对话/轨迹"标签、插件页"插件配置/列表"标签。

| 状态 | 表现 |
|---|---|
| 静止 | 官方原样（无底色） |
| ⭐悬停 | 淡粉 40%/32% + blur 6px + 顶高光（原 30%/22%，2026-08-18 加深一档） |
| 按下 | 悬停色保留 + brightness(0.9) + 内凹（呈浅灰粉） |

⭐悬停原则：**从无到有**，淡粉是"提示"而非"强调"。

### C 类 · 蓝色主按钮（发送/停止）

- 常驻：官方蓝 + 顶部柔光渐变；⭐悬停：**黑 7% 叠加 + 保留柔光（蓝加深一档，须自己补，常驻 !important 会压死官方 hover）**；
- 按下：暗色叠加 12% + 内凹。

### D 类 · 兜底（未单独定制的所有按钮）

- ⭐悬停：无定制（官方原样）；按下：brightness(0.9) + 内凹（深浅模式通用）。
- **静止圆角**：所有兜底按钮统一 8px 圆角矩形——用 `body:where(:not([data-ds-dark-theme])) button`（**:where 零特异性**）实现：只有没有自己圆角样式的按钮才生效，任何官方/皮肤的类级圆角（12/18/24px 胶囊等）都自动保持正常幅度，不再需要逐个排除。

### 特例

- **弹窗右上角关闭图标钮**：悬停用 **A 类粉玻璃 62%/44% + 白图标**（30% 淡粉在粉底上不可见，所以不能用 B 类）。
- **插件列表卡片**：标题 = 完整 12px 圆角矩形深粉块（65%/50%，z-index 压住详情）；详情 = 加深粉（250,222,238 95%/244,208,230 90%）下圆角 12px、上边被标题压住；卡片底 = 详情色消除空隙。悬停/展开态 = 左侧选项款 86%/70%。

## 三、⭐悬停工程铁律（踩过的坑）

1. **基础规则带 `!important` 会压死悬停**——悬停规则必须写在同一权重、排在基础之后，且自己也带 `!important`。
2. **30% 以下的粉色在浅粉玻璃上≈隐形**——"悬停没反应"先怀疑数值太淡，再怀疑选择器。
3. **`:active` 必须写在 `:hover` 之后**（同权重后者赢）。
4. **通用 button 选择器要带豁免名单**（菜单条目、卡片标题按钮等会被误伤）。
5. **backdrop-filter 不能套在"内部有 fixed 弹层"的容器上**（玻璃放 ::before；侧栏/弹窗教训）。
6. **弹窗/悬浮层常 portal 到 body**——针对它们的规则不能用面板类限定作用域。
7. **圆角卡片一律配 overflow:hidden**，防止内部直角溢出。
8. **类名版本脆弱**——核对服务器实际发出的包（/plugins/<包名>/client.js），别只信 node_modules。
9. **展开态微调（width/margin/padding）会泄漏进收起模式**——收起模式全部控件（切换/新会话/添加工作区/搜索/设置/会话日志）统一 36×36 + 横向居中 + 粉色玻璃（55%/40%），靠 `.hHd-Xa_collapsed` 覆盖规则兜底；工作区插件的类（qDHVXG_*）要单独写。形状：切换/新会话/添加/搜索/设置 = 12px 圆角矩形；会话日志暂保持官方圆形。交互：全部走 A 类——悬停同轴加深一档（55/40→75/62；新会话/设置/日志 62/44→82/66），按下实色 85% + 内凹，不用 B 类提亮。

## 四、菜单颜色逻辑（与对话气泡同款）

- 面板：粉 78%/55% + blur 10px saturate 155% + 白边 60% + 上高光/下粉影/粉紫投影。
- 条目：默认透明 → 悬停玻璃加深（白纱 + 深粉 22%，原 14%，2026-08-18 加深一档）→ 按下实色粉 45% + 去模糊 + 内凹。
- **菜单条目的 `:focus-visible` 一律不上粉**（点击后焦点残留会变成"永久悬停"，交还官方默认）。
- **斜杠命令面板（`/`）例外**：官方把"悬停=移动高亮"写死在 JS 里（`onMouseEnter → highlight(index)`，打开时 `active:0` 选中第一行），所以不加 CSS `:hover`；目标行 `.mufS8W_rowActive` 做成实心深粉（236,72,153 88% / 220,60,140 70%）+ 白字 + 右侧 ↵ 提示，按下 = 黑 14% 叠加深 + 内凹。
- 打字区四个菜单面板统一此配方；弹窗面板 = 浅一档（252,228,240 88%/72%）。

## 五、轨迹界面（设计语言同款）

- 根底透明露出壁纸；工具栏/详情面板 = 淡粉玻璃（253,240,247 96%/249,232,242 92%）；主分栏 = 94%/90% 无 backdrop-filter。
- 吸顶表头/加载条 = 淡粉纱幕 96%/94% + blur 8（官方用 sidebar-fill=透明，必须自补）。
- 行悬停 = B 类 40%/32%；选中行 = 白纱 + 深粉 16%；工具栏按钮 = A 类设置面板款（65%/50% + 黑字，24px 高 8px 圆角，悬停 86%/70%，按下实色 92%+内凹）；工具栏内边距 12px 与卡片边框留缝；激活详情标签 = 粉字 #ec4899 + 粉下划线。
- 轨迹界面隐藏底部输入框/统计条（`:has(.qBU-ya_root)`），底部留白收回 16px。
- 整体 = 悬浮液态玻璃卡片 + 背后 viewArea 玻璃（两层同为**白玻璃 45%/28% + blur 14 + saturate 160**，透光优先；侧栏仍为 62%/42%），四周 margin 上 102px / 左 30px / 右 12px / 下 12px；**卡片背后的整块 viewArea 也是同款液态玻璃**（`body:has(.qBU-ya_root) .wSkVaW_viewArea`），缝隙不再露白。
- 详情面板内部层级（全部圆角）：面板 80%/62% → 正文区 90%/85% → 摘要卡/统计/单行详情 95%/85%（12/10px）→ Summary 预览区/Schema 页 95%/88%（10px）→ 工具目录定义区 95%/90%（8px）；**轨迹详情代码界面 = 终端卡片样式**（代码正文平粉 253,242,248 95%/250,236,245 90% + 白边 + 12px 圆角 + 黑等宽字 + 弱阴影；**层叠结构（全详情界面通用，范围 = 所有标题与内容框）：标题块（overviewHeading/promptDiffTitle/toolCatalogSummary/sourceBlockHeader/schemaIntro/parametersTitle/usageHeading）= 完整圆角矩形加深深粉 246,175,205 80%/238,160,195 65% + 投影（凸起）+ z-index 2，压在正文上；**标题块交互：悬停加深 240,160,196 90%/228,148,188 78%；整块标题按压反馈（235,150,190 96%/222,138,182 88% + 内凹 + 10px 圆角）保留；标题中间文字部分（overviewTitle）不设自己的按压反馈**；（JS 捕获阶段转发：点标题任意位置 = 触发内部 overviewTitle 按钮的 onOpen——注意官方结构里跳转链接不在标题块内，转发目标必须是 overviewTitle；点标题按钮本身不重复触发；含链接的标题显示手型光标）；正文框（overviewSection/overviewPreview/schema/usagePanel/promptDiffSection/sourceBlockContent/toolCatalogDefinition）= 中粉 250,222,238 95%/244,208,230 90% + 下圆角，上边被标题覆盖；第三层（schemaTree/usage 内容）= 下凹：暗一档 243,205,228 90%/236,190,218 82% + 内阴影，不做凸起；多层级以此类推**）；快照：`client.js.snap-20260818-layered`。标签/行号小片 = 半透明白粉（4-6px 圆角）。详情标签（Payload/Summary 等同级按钮）= 静止透明 + 10px 圆角 → 悬停变深 40%/32% + 顶高光 → 按下 60%/50% + 内凹；**悬停/按下都显式带 10px 圆角（全程圆角矩形）；激活下划线 = 圆角胶囊（999px / 3px 高）**。
- **对话消息里的代码（内联小片 + 代码块）= 浅蓝玻璃（226,239,254 78%/199,222,254 55%）——定稿设计，永不粉化。**
- **输入框默认占位符改写**：`给智能体发消息` → `给Kaguya发消息`（运行时 MutationObserver 补丁，仅默认占位符；计划/目标/不可用等官方占位符不动）。
- 时间线条（`_1p9O6q_plot`）= 粉玻璃带（250,205,222 55% / 240,170,198 42%），与下方表格区分；语义色段不动，分割线/标签边框提亮为白色。
- 语义色（绿/黄/紫/红状态点、turn rail 等）一律不碰。
