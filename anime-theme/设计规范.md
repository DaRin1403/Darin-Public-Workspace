## 一、三条军规

1. **浅色限定**：所有规则挂在 `body:not([data-ds-dark-theme])` 下，深色模式 100% 官方原样。
2. **语义色不碰**：蓝（业务/运行）、红（错误）、绿（成功）、黄（警告）永不改色。
3. **墙式结构**：官方 13 面 token 墙，只刷 3 面——主色（#ec4899）、侧栏底（transparent）、整页背景（立绘层 + 背景图 + #fdf3f8）。

## 三、按钮与交互

### 四类按钮
| 类 | 定义 | 三态 |
|---|---|---|
| A 粉玻璃重按钮 | 有身份的常驻粉色 | 常驻 62%/44%+白字 → **悬停 = var(--kaguya-hover) 艳粉** → 按下实色 85%+内凹 |
| A-设置面板款 | 更淡+黑字 | 65%/50%+#222 → **悬停 = var(--kaguya-hover)** → 92%+内凹 |
| A-弹窗主按钮款 | 深一档 | 72%/55% → **悬停 = var(--kaguya-hover)** → 95%+内凹 |
| B 轻按钮 | 静止无底色 | 悬停淡粉 40%/32%+顶高光 → 按下 brightness(0.9)+内凹 |
| C 蓝色发送键 | 语义蓝 | 悬停黑 15% 叠加（2026-08-19 由 7% 加深）；按下黑 22%+内凹 |
| D 兜底 | 其它所有按钮 | 按下 brightness(0.9)+内凹；静止圆角 8px（`:where` 零特异性，不压任何类级圆角） |

### 悬停颜色统一变量（重要）
- 变量组（全部 A 类粉色按钮 + 输入区菜单条目绑定）：
  - L0 常驻：`--kaguya-base`（主款 238,120,180 72%/224,100,165 55%）、`--kaguya-base-soft`（设置面板款 246,175,205 75%/238,160,195 62%）、`--kaguya-base-rail`（收起模式 65%/50%）；
  - 悬停/选中：`--kaguya-hover`（艳粉 236,90,163 95%/85%）、`--kaguya-hover-soft`（70%/55%）；
  - **按下：`--kaguya-press`（黑 12% 叠加在艳粉之上 = 一定比悬停更深）**——三态梯度铁律：常驻 < 悬停 < 按下，任何一次改悬停后必须检查按压是否仍更深。
- **蓝色发送/停止键 = 语义色单元，不绑艳粉变量**：悬停保持官方蓝加深（黑 7% 叠加+柔光）、按下黑 12%+内凹。曾误绑 var(--kaguya-hover)，已解绑恢复。
- 铁律：统一规则的豁免链必须与常驻规则**同长**（6 个 `:not`），少一个就被压住。

### 特例

## 八、工程铁律 TOP10

1. 常驻规则带 `!important` 必压死悬停——悬停规则要同权重、排在后面、自己也 `!important`。
2. 通用 button 选择器要带豁免名单，且豁免链长度必须与常驻规则一致（差一个就失效）。
3. `:active` 写在 `:hover` 之后。
4. backdrop-filter 别套在"内部有 fixed 弹层"的容器上——玻璃放 `::before`。
5. 弹窗/浮层常 portal 到 body，规则不能用面板类限定作用域。
6. 圆角卡片配 overflow:hidden。
7. 展开态微调会泄漏进收起模式，收起态用 `.hHd-Xa_collapsed` 兜底。
8. 类名是哈希且随版本变——核对服务器实际发出的包（/plugins/.../client.js）。
9. 30% 以下的粉色在浅粉玻璃上≈隐形。
10. 图片全部 webp + 单图 <1MB（原图直嵌 27MB 会让图片整体消失）；JS 注释里别用中文双引号。
