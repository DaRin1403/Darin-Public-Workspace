# Kaguya 皮肤 · 设计语言（一页版）

> 详细规则查 `设计规范.md`（规则手册 v2）；架构与预案查 `交互架构方案.md`。

## 一句话

**樱花粉 × 液态玻璃 × 三态一致交互**，只动浅色模式。

## 液态玻璃四件套

半透明渐变（模拟厚度）＋ backdrop 模糊（真实模糊背后）＋ 白色亮边与内高光 ＋ 粉紫外投影（浮起来）。

## 颜色：一根粉色轴

- 品牌色 `#ec4899`，一切可交互色都是它的同轴深浅；
- 玻璃白轴（侧栏 62%/42%）与玻璃粉轴（菜单 78%/55%）两条明度线；
- 输入区悬停用艳粉 `--kaguya-hover`（236,90,163），一处改全局生效；
- 对话代码 = 浅蓝玻璃（定稿特例）；语义色（蓝红绿黄）永不碰。

## 形状

侧栏玻璃 18px / 卡片与按钮 12px / 胶囊 999px / 收起模式 36×36 圆角矩形。

## 交互手语

静止 → 悬停（同轴加深一档）→ 按下（实色 + 内凹）；菜单"悬停 = 选中"；斜杠面板"目标行 = 实心深粉 + ↵"。

## 思路（七条）

1. 墙式结构：13 面墙只刷 3 面，改动面最小；
2. 浅色限定：深色模式 100% 官方；
3. 语义色军规：好看不能让状态看不懂；
4. 按钮四大类：A 重 / B 轻 / C 蓝（语义）/ D 兜底；
5. 三态一致：全 UI 同一套手语；
6. 菜单统一配方：面板同气泡、条目同悬停；
7. 像素级迭代：改 → F5 → 截图诊断 → 微调 → 规范沉淀。

## 与原版对比

| 维度 | 原版 | 本皮肤 |
|---|---|---|
| 配色 | 中性蓝灰、白卡 | 樱花粉玻璃 |
| 背景 | 纯色 | 立绘 + 背景图双层 fixed |
| 侧栏 | 贴边纯色 | 悬浮玻璃窗格 + 立绘 |
| 按钮 | 官方蓝 + 灰 hover | A/B/C/D 四类、粉三态、内凹按压 |
| 菜单悬停 | 灰 | 粉玻璃加深 |
| 深色模式 | 官方 | 完全一致（零改动） |

## 优劣一句话

**用官方 1/3 的改动面换来完整世界观与统一三态交互；代价是粉色对比度上限与类名维护依赖。作为个人专属皮肤，性价比很高。**
