# Kaguya 皮肤 · 设计语言总结（最终稿）

> 从最终定稿的 `lib/client.js` + `设计规范.md` 提炼。
> 一句话：**樱花粉 × 液态玻璃 × 三态一致交互**，只动浅色模式。

---

## 一、设计语言（Design Language）

**主风格：液态玻璃（Liquid Glass，Apple 风）**

四件套配方（贯穿全皮肤）：

1. 半透明白/粉渐变底色（模拟玻璃厚度）
2. `backdrop-filter: blur + saturate`（真实模糊背后内容）
3. 亮边与内高光（`inset` 白色上高光 + 粉色下内影）
4. 柔和外投影（粉紫色调，元素"浮"在背景上）

**色彩系统：一根粉色轴**

- 品牌色 `#ec4899`（樱花粉），所有可交互色都是它的同轴深浅变体
- 面板玻璃：粉 78%/55% 渐变 + blur 10 + saturate 155%
- 浅色限定：`body:not([data-ds-dark-theme])` 门控，**深色模式 100% 官方原样**

**形状语言**：侧栏玻璃 18px 圆角 / 卡片与按钮 12px / 胶囊 999px / 收起模式 36×36 圆角矩形。

**光影语言**：上高光（白）→ 主体渐变 → 下内影（深粉）→ 外投影（粉紫），四层同构。

---

## 二、设计思路（Design Philosophy）

1. **墙式结构**：官方主题把界面分成 13 面"墙"（token），本皮肤只刷 3 面（主色、侧栏底色、整页背景），其余 10 面全部保持官方——改动面最小，风险可控。
2. **浅色限定**：所有规则用 `:not([data-ds-dark-theme])` 门控，夜晚模式完全官方，白天才进入樱花世界。
3. **语义色军规**：红/绿/黄/蓝（运行态、错误、成功、警告）永不改色——好看不能让状态看不懂。
4. **按钮四大类**：A 粉玻璃重按钮（有身份）/ B 轻按钮（悬停才显形）/ C 蓝色发送键（保留官方蓝）/ D 全局兜底（按压反馈），每个按钮都能在四类里找到自己的位置。
5. **三态一致交互**：静止 → 悬停（同轴加深一档）→ 按下（实色 + 内凹），全 UI 同一套手语。
6. **菜单统一配方**：面板与对话气泡同款玻璃；条目悬停 = 选中 = 同一视觉（选中所见即所得）。
7. **像素级迭代**：VSCode 改 → F5 看 → 截图给视觉模型诊断 → 数值微调（1px/2px 级别）→ 设计规范沉淀，文档与代码同步进化。

---

## 三、重要特点（Key Features）

- **双层背景**：整页背景 = 玻璃后立绘（kaguya_1，85% 不透明度）+ 全幅背景图 + 樱花白底，`fixed` 定位实现滚动时人物不动。
- **悬浮玻璃侧栏**：侧栏是独立玻璃窗格（18px 圆角、白边、立绘压在 `::before` 上），内部内容全部透明化。
- **侧栏立绘**：Kaguya_Q 透明通道裁剪版，置于侧栏底部。
- **收起模式一致性**：六个控件（切换/新会话/添加/搜索/设置/日志）统一 36×36、同中线、同粉玻璃、12px 圆角矩形。
- **斜杠命令面板目标行**：实心深粉 + 白字 + 行尾 `↵` 回车提示，一眼知道回车执行哪行。
- **悬停工程铁律**：`!important` 压死悬停、`:active` 须在 `:hover` 后、backdrop-filter 不能套在有 fixed 弹层的容器上、菜单条目 `:focus-visible` 不上粉（避免"永久悬停"）等 9 条踩坑结论。
- **素材内嵌**：图片经 `build-skin.cjs` 压缩成 webp + base64 直接打进皮肤包，无外链、无路径问题。
- **持久化**：通过 `cordis.patch.yml` 挂载真实 npm 包（非动态插件），重启不丢。

## 四、与原版的区别

| 维度 | 原版（官方） | 本皮肤 |
|---|---|---|
| 配色 | 中性蓝灰、白卡片 | 樱花粉玻璃、樱花白底 `#fdf3f8` |
| 背景 | 纯色 | 全幅背景图 + 人物立绘双层 |
| 侧栏 | 纯色填充、贴边 | 悬浮玻璃窗格 + 立绘 + 阴影 |
| 按钮 | 官方蓝主按钮、灰 hover | A/B/C/D 四类、粉色三态、按压内凹 |
| 收起模式图标 | 圆形（border-radius 50%） | 36×36 圆角矩形、统一粉玻璃 |
| 菜单悬停 | 灰 `interactive-bg-hover` | 粉玻璃加深（白纱 + 深粉 22%） |
| 命令面板目标行 | 灰色高亮 | 实心深粉 + 白字 + ↵ 提示 |
| 设置面板 | 白底 | 极淡粉玻璃 |
| 深色模式 | 官方暗色 | **完全不动（与官方一致）** |

## 五、与原版的优劣

### 优势

1. **沉浸感与个性**：立绘 + 玻璃 + 樱花粉形成完整世界观，远超官方中性风的表现力。
2. **交互反馈完整**：官方多处只有灰 hover；本皮肤全 UI 三态分明（加深 + 内凹），操作"手感"一致。
3. **浅色限定 = 风险隔离**：深色模式零改动，升级或切换主题无副作用。
4. **语义色保留**：状态颜色不牺牲，可读性与安全性不降。
5. **工程化**：13 面墙精确分工、文档同步、备份可回滚、类名与官方包逐条核对。

### 代价 / 风险

1. **对比度上限低**：粉色系在浅粉玻璃上天生柔和，30% 以下透明度几乎隐形，深色文字偏少；追求"明显"必须牺牲"柔和"。
2. **性能开销**：大量 `backdrop-filter` 模糊层（侧栏、头部、菜单、气泡）在低端设备上可能掉帧。
3. **升级脆弱**：依赖官方哈希类名（如 `.hHd-Xa_*`、`._7KE1Ra_*`），官方一改版类名就失效，需要长期维护。
4. **普适性弱**：高度个性化，属于"专属皮肤"而非"通用主题"。
5. **可读性折损点**：半透明面板叠在立绘/图片上时，局部文字对比度依赖背景明暗，偶有看不清楚的情况。

### 一句话结论

**用官方 1/3 的改动面（3 面墙 + 一层 CSS），换来了完整的视觉世界观和统一的三态交互；代价是粉色系的对比度天花板和对官方类名的维护依赖。作为个人专属皮肤，性价比很高。**
